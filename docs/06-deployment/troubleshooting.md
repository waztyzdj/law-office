# 常见问题

## 登录失败

检查：

- 数据库中用户是否存在。
- 用户状态是否正常。
- 密码是否为 BCrypt 摘要。
- Redis 是否可用。
- JWT 配置是否一致。

## 菜单为空

检查：

- 用户是否绑定角色。
- 角色是否绑定权限。
- `sys_permission` 中菜单状态是否启用。
- 前端是否正确获取权限码和菜单。

## 列表无数据

检查：

- `delete_flag` 是否为 `0`。
- 租户上下文是否正确。
- 查询条件是否被前端筛选持久化影响。

## 导入导出失败

检查：

- 文件是否为空。
- Excel 表头是否与 Entity 导出注解匹配。
- 响应头是否正确。
- 是否包含敏感字段或未授权数据。
