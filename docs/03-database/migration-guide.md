# 数据库变更规范

## SQL 文件

当前建表脚本位于：

```text
sql/建表脚本.sql
```

## 变更流程

1. 修改或新增 SQL。
2. 同步更新 Entity、Req、VO、Mapper 和 Service。
3. 同步更新前端表单、表格列、接口类型。
4. 更新 `docs/03-database/` 和对应模块文档。
5. 涉及权限、菜单、字典初始化数据时，同步更新接口和前端权限常量。

## 设计要求

- 新表必须包含主键和必要审计字段。
- 多租户业务表必须包含 `tenant_id`。
- 高频查询字段必须建立索引。
- 唯一业务约束必须建立唯一索引。
- 字段长度要与前端校验、Req 校验保持一致。
