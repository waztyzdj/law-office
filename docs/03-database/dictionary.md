# 字典与枚举

本文件记录系统中需要前后端保持一致的状态值、枚举和字典。

## 用户状态

| 值 | 说明 |
| --- | --- |
| `1` | 正常 |
| `2` | 冻结 |

## 性别

| 值 | 说明 |
| --- | --- |
| `0` | 未知 |
| `1` | 男 |
| `2` | 女 |

## 逻辑删除

| 值 | 说明 |
| --- | --- |
| `0` | 未删除 |
| `1` | 已删除 |

## 权限动作

| 动作 | 说明 |
| --- | --- |
| `view` | 查看、列表、详情、导出 |
| `edit` | 新增、修改、删除、导入 |

## 维护要求

- 新增状态值时同步更新后端常量/枚举、前端展示、数据库注释和模块文档。
- 字典表中的业务字典要补充字典编码、字典项和使用位置。
