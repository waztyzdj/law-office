# 安全设计

## 认证

- 登录接口：`POST /auth/login`。
- 登录成功后返回 token 和默认租户 ID。
- token 由后端生成并存储到 Redis。
- 请求过滤器解析 token，并将用户信息写入请求上下文。

## 授权

- 后端通过 `PermissionAspect` 拦截接口。
- 标准 CRUD 根据模块信息和方法语义计算权限。
- 自定义接口可通过 `@RequiresPermission` 显式声明权限。
- 前端通过权限码控制菜单和按钮。

## 密码

- 密码使用 BCrypt 校验和存储。
- 修改密码必须校验旧密码。
- 登录失败日志不得泄露密码。

## 租户隔离

- 租户信息由登录态和请求上下文提供。
- 多租户数据通过租户字段和 MyBatis-Plus 租户处理器隔离。
- 请求结束必须清理租户上下文。

## 敏感信息

以下信息不得完整输出到日志或普通接口：

- 密码、salt。
- token。
- 身份证号、手机号、邮箱。
- 数据库、Redis、MinIO、JWT 密钥。
