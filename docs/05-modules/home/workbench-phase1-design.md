# 工作台一期设计文档

## 文档目的

本文用于固定工作台一期的建设范围和设计边界。工作台不绑定具体行业业务模块，而是复用系统已具备的审批中心、文档中心、消息中心和菜单权限等横向能力，先形成通用管理系统的首页能力。

## 阶段定位

工作台是用户登录后的个人工作入口，重点解决三类问题：

- 聚合用户当前需要处理和关注的事项。
- 提供高频功能的快捷入口。
- 通过轻量指标帮助用户快速判断工作状态。

一期先建设可复用的工作台框架和基础卡片，不提前实现复杂业务域看板、跨模块经营分析或大屏报表。统计报表中心后续独立设计，工作台只展示可快速下钻的轻量指标。

## 依赖能力

一期优先复用以下已实现或已规划稳定的系统能力：

- 审批中心：待办、已办、我发起的、抄送、催办、超时提醒、流程监控和归档等数据。
- 文档中心：我的文档、业务文档、共享给我、最近文件、文档权限和业务文档 Provider。
- 消息中心：未读通知、收件箱、消息动作、待办提醒和文件消息。
- 菜单权限：`sys_permission` 菜单、子菜单和按钮权限点，角色授权和部门授权。

## 一期范围

一期实现以下工作台能力：

1. 工作台菜单和访问权限。
2. 首页卡片配置管理。
3. 用户个性化布局和显隐设置。
4. 我的待办卡片。
5. 我的抄送卡片。
6. 快捷入口卡片。
7. 我的消息卡片。
8. 指标概览卡片。

## 非一期范围

以下能力不纳入工作台一期：

- 独立统计报表中心、报表设计器、复杂图表建模和指标口径管理。
- 管理驾驶舱、监控大屏、跨租户经营分析和定时统计快照。
- 针对案件、合同、项目、采购等具体业务模块的专属卡片。
- 移动端专项首页交互。
- 首页卡片组件的在线代码编辑、脚本执行或任意前端组件路径加载。

## 菜单与权限设计

工作台作为用户端顶级菜单建设，不在工作台菜单下继续挂卡片子菜单。工作台卡片管理属于系统管理能力，页面代码仍按 `home/admin/card` 的业务域组织，菜单入口由系统管理菜单承载。

建议权限点：

| 权限码 | 类型 | 说明 |
| --- | --- | --- |
| `home:workbench:view` | 菜单权限 | 访问工作台页面。 |
| `home:card:todo` | 按钮权限 | 查看我的待办卡片。 |
| `home:card:cc` | 按钮权限 | 查看我的抄送卡片。 |
| `home:card:quick-entry` | 按钮权限 | 查看快捷入口卡片。 |
| `home:card:message` | 按钮权限 | 查看我的消息卡片。 |
| `home:card:favorite` | 按钮权限 | 查看我的收藏卡片。 |
| `home:card:metrics` | 按钮权限 | 查看指标概览卡片。 |
| `home:card:manage` | 菜单/按钮权限 | 管理工作台卡片配置和系统默认快捷入口。 |

关键规则：

- 卡片权限使用 `sys_permission.menu_type=2` 的按钮权限点承载，不把每个卡片建成工作台子菜单。
- 工作台菜单只负责导航入口，工作台卡片是页面内的信息组件，由工作台卡片配置管理。
- 卡片配置中如果设置了权限码，用户必须拥有该权限点才可看到卡片。
- 卡片配置中如果未设置权限码，则默认所有拥有 `home:workbench:view` 的用户可见。
- 前端按权限控制卡片展示，后端卡片数据接口仍必须校验登录态、租户、卡片权限和业务数据访问权。
- 卡片组件不允许从数据库动态加载任意组件路径，只能选择前端预置的 `componentKey` 白名单。

## 工作台卡片配置

工作台卡片管理功能由系统管理员维护，用于控制系统允许出现哪些卡片、默认如何展示、哪些角色或用户可见。

建议配置字段：

| 字段 | 说明 |
| --- | --- |
| `cardCode` | 卡片编码，同租户内唯一，例如 `todo`、`cc`、`message`、`favorite`、`metrics`。 |
| `cardName` | 卡片名称，用于工作台标题和管理端展示。 |
| `componentKey` | 卡片组件标识，只允许从前端注册表中选择。 |
| `permissionCode` | 卡片权限码，可为空；为空时默认拥有工作台访问权的用户可见。 |
| `enabled` | 是否启用；停用后所有用户不可见。 |
| `defaultVisible` | 默认是否显示；用户可在个性化中隐藏。 |
| `defaultSort` | 默认排序。 |
| `defaultSize` | 默认尺寸，例如 `small`、`medium`、`large`、`full`。 |
| `defaultRefreshInterval` | 默认刷新间隔，避免高频轮询。 |
| `configJson` | 卡片扩展配置，例如列表每页行数、统计范围、快捷入口来源。 |
| `remark` | 备注。 |

管理端第一版能力：

- 新增、编辑、启用、停用卡片配置。
- 调整默认排序和默认尺寸。
- 为卡片绑定权限码。
- 选择预置组件。
- 配置卡片展示条数、刷新间隔等基础参数。
- 查看卡片被哪些权限点控制，避免管理员误以为配置后所有人立即可见。

## 用户个性化设置

用户个性化只影响当前用户自己的工作台布局，不改变系统默认卡片配置。

一期支持：

- 卡片显示和隐藏。
- 卡片位置拖拽调整。
- 卡片宽度和高度拖拽调整。
- 恢复系统默认布局。
- 快捷入口个人配置。

关键规则：

- 用户只能配置自己有权查看且系统已启用的卡片。
- 管理员停用卡片后，即使用户个性化中曾经显示该卡片，也不再展示。
- 管理员取消某个卡片权限后，失去权限的用户不再展示该卡片，用户个性化记录保留但不生效。
- 用户新增个性化记录前，默认布局由启用卡片、权限码、`defaultVisible`、`defaultSort` 和 `defaultSize` 共同计算。
- 工作台默认浏览态不显示拖拽和缩放控件；用户点击右下角设置按钮进入编辑态后，才显示拖拽、缩放和卡片隐藏入口。
- 编辑态右下角显示加号和确认按钮：加号打开卡片显隐设置，用于恢复隐藏卡片；确认按钮统一保存本次拖拽、缩放、隐藏和恢复结果。
- 恢复默认布局只清理当前用户个性化配置，不影响管理员配置。
- 个性化配置必须按租户和用户隔离。

建议个性化字段：

| 字段 | 说明 |
| --- | --- |
| `userId` | 用户 ID。 |
| `tenantId` | 租户 ID。 |
| `cardCode` | 卡片编码。 |
| `visible` | 当前用户是否显示。 |
| `sortNo` | 当前用户内部排序，由服务端根据栅格位置派生，用于兼容旧布局和无坐标兜底，不在个性化界面手工维护。 |
| `size` | 当前用户尺寸。 |
| `gridX` / `gridY` | 当前用户拖拽后的栅格位置，从 `0` 开始。 |
| `gridW` / `gridH` | 当前用户调整后的卡片宽度和高度；宽度按 12 列栅格计，高度按行高单位计。 |
| `configJson` | 预留用户级扩展配置；一期不用于列表每页行数，卡片展示行数以管理员卡片配置为准。 |

## 一期卡片设计

### 我的待办卡片

卡片编码：`todo`

组件标识：`WorkbenchTodoCard`

建议权限码：`home:card:todo`

数据来源：

- 审批中心我的待办。
- 审批中心我的已办。
- 后续业务模块注册的待办 Provider。

功能：

- 展示当前用户待处理和已办理事项数量。
- 卡片内分为“我的待办”和“我的已办”两个 Tab。
- 我的待办按任务到达时间倒序排列，我的已办按办理时间倒序排列。
- 支持点击事项进入办理页或详情页。
- 支持展示超时、即将超时、普通三类状态。

边界：

- 一期不在卡片内直接完成复杂审批动作，点击后进入对应办理页面。
- 待办权限以业务模块数据权限为准，工作台不绕过审批中心和消息中心的访问规则。

### 我的抄送卡片

卡片编码：`cc`

组件标识：`WorkbenchCcCard`

建议权限码：`home:card:cc`

数据来源：

- 审批中心我的抄送。

功能：

- 展示当前用户未读抄送和已读抄送数量。
- 卡片内分为“未读抄送”和“已读抄送”两个 Tab。
- 两个 Tab 均按抄送到达时间倒序排列。
- 每条记录显示流程标题和抄送到达时间。
- 支持点击抄送记录进入我的抄送页面，并打开对应流程详情。

边界：

- 工作台只展示抄送入口和状态，不在卡片内直接处理已读状态变更。
- 抄送访问权限以审批中心我的抄送数据权限为准，工作台不绕过审批中心访问规则。

### 快捷入口卡片

卡片编码：`quick-entry`

组件标识：`WorkbenchQuickEntryCard`

建议权限码：`home:card:quick-entry`

数据来源：

- 当前用户有权访问的菜单。
- 管理员配置的系统默认入口。
- 用户个性化配置的个人常用入口。

功能：

- 展示高频菜单和动作入口。
- 支持用户添加、移除和排序个人快捷入口，个人入口支持内部菜单和外部链接。
- 支持管理员配置默认快捷入口，例如发起审批、文档中心、消息中心、流程监控。
- 快捷入口点击后进入对应菜单、打开外部链接或触发指定业务动作。

边界：

- 只展示当前用户有权访问的菜单或动作。
- 外部链接必须校验协议，仅允许 `http://` 和 `https://`，并以新窗口打开。

### 我的消息卡片

卡片编码：`message`

组件标识：`WorkbenchMessageCard`

建议权限码：`home:card:message`

数据来源：

- 消息中心收件箱。
- 审批中心通过消息中心产生的审批结果提醒、待办提醒、催办提醒和超时提醒。

功能：

- 展示未读消息、已读消息、未读催办和未读超时提醒数量。
- 卡片内默认分为“未读消息”和“已读消息”两个 Tab。
- 存在未读催办消息时显示“催办”Tab，存在未读超时提醒时显示“超时”Tab，顺序为“催办、超时、未读、已读”；无对应未读消息时隐藏动态 Tab。
- 默认选中优先级为“催办、超时、未读”；前一类存在时，后一类不作为默认 Tab。
- 各 Tab 均按消息到达时间倒序排列。
- 每条记录显示消息标题和到达时间。
- 支持点击消息动作进入审批详情、待办办理、文档预览或消息详情。

边界：

- 个人消息能力不依赖菜单权限，但工作台卡片展示仍可通过卡片权限控制。
- 消息附件下载仍通过消息模块接口鉴权，不从工作台直接暴露文件地址。

### 我的收藏卡片

卡片编码：`favorite`

组件标识：`WorkbenchFavoriteCard`

建议权限码：`home:card:favorite`

数据来源：

- 通用文件元数据表 `sys_files` 中当前用户已收藏且未删除的文件，以及收藏文件夹下可访问的真实文件。
- 工作台卡片只铺开展示文件，不展示文件夹本身；文档中心“我的收藏”仍保留原有文件夹浏览入口。

功能：

- 展示当前用户收藏文件数量；收藏文件夹下铺开的文件计入文件数量。
- 列表按收藏时间倒序排列；收藏文件夹下铺开的文件使用对应收藏文件夹的收藏时间排序。
- 每条记录显示文件类型对应图标、文件名称、收藏时间和下载按钮。
- 右上角跳转进入文档中心“我的收藏”。
- 双击明细直接打开文档预览；不支持在线预览的文件提示用户下载后查看。
- 右侧下载按钮直接下载当前文件；底部复用工作台卡片分页组件。

边界：

- 工作台不直接暴露文件下载地址，不绕过文档中心权限校验。
- 收藏时间以 `sys_files.star_time` 为准；历史收藏没有该字段值时，由迁移脚本回填更新时间或创建时间。
- 业务文档、共享文档等访问权限仍以文档中心自身规则为准。

### 指标概览卡片

卡片编码：`metrics`

组件标识：`WorkbenchMetricsCard`

建议权限码：`home:card:metrics`

数据来源：

- 审批中心当前用户待办数据。
- 审批中心当前用户抄送数据。
- 消息中心当前用户消息通知数据。

功能：

- 展示当前用户维度的轻量指标：我的待办、我的抄送、我的消息。
- 支持点击指标下钻到对应模块列表。

边界：

- 指标概览不是统计报表中心，不承担复杂图表、跨租户经营分析和自定义指标口径。
- 指标必须有明确口径，优先使用各业务模块自身表和接口，不直接暴露底层引擎历史表。
- 指标查询必须考虑性能，必要时限制时间范围或使用模块已有统计接口。

## 卡片组件注册

前端应维护工作台卡片组件注册表，数据库只保存 `componentKey`。

注册表示例：

| `componentKey` | 组件 | 说明 |
| --- | --- | --- |
| `WorkbenchTodoCard` | 我的待办卡片 | 展示用户待办和已办。 |
| `WorkbenchCcCard` | 我的抄送卡片 | 展示用户未读和已读抄送。 |
| `WorkbenchQuickEntryCard` | 快捷入口卡片 | 展示常用入口。 |
| `WorkbenchMessageCard` | 我的消息卡片 | 展示未读和已读消息。 |
| `WorkbenchFavoriteCard` | 我的收藏卡片 | 铺开展示用户收藏的文件。 |
| `WorkbenchMetricsCard` | 指标概览卡片 | 展示轻量指标。 |

关键规则：

- 未注册的 `componentKey` 不渲染，并在管理端提示配置异常。
- 卡片组件必须提供 loading、empty、error、disabled 和无权限状态。
- 卡片组件内部不能信任前端权限结果，调用数据接口时仍依赖后端鉴权。

## 接口方向

工作台接口建议统一使用 `/home/workbench` 前缀，管理端使用 `/home/admin/workbench` 前缀，延续项目后台接口 `POST + body` 风格。详细请求、响应和约束以 `docs/04-api/home-api.md` 为准。

建议接口：

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| POST | `/home/workbench/layout` | `home:workbench:view` | 查询当前用户可见卡片和个性化布局。 |
| POST | `/home/workbench/layout/save` | `home:workbench:view` | 保存当前用户卡片布局。 |
| POST | `/home/workbench/layout/reset` | `home:workbench:view` | 恢复当前用户默认布局。 |
| POST | `/home/workbench/card/data` | `home:workbench:view` + 卡片权限 | 查询单个卡片数据。 |
| POST | `/home/workbench/quick-entry/list` | `home:workbench:view` + `home:card:quick-entry` | 查询当前用户快捷入口。 |
| POST | `/home/workbench/quick-entry/save` | `home:workbench:view` + `home:card:quick-entry` | 保存当前用户个人快捷入口。 |
| POST | `/home/workbench/quick-entry/delete` | `home:workbench:view` + `home:card:quick-entry` | 删除当前用户个人快捷入口。 |
| POST | `/home/admin/workbench/card/page` | `home:card:manage` | 分页查询首页卡片配置。 |
| POST | `/home/admin/workbench/card/detail` | `home:card:manage` | 查询首页卡片配置详情。 |
| POST | `/home/admin/workbench/card/save` | `home:card:manage` | 新增或编辑首页卡片配置。 |
| POST | `/home/admin/workbench/card/status` | `home:card:manage` | 启用或停用首页卡片。 |
| POST | `/home/admin/workbench/card/sort` | `home:card:manage` | 调整默认排序。 |
| POST | `/home/admin/workbench/quick-entry/page` | `home:card:manage` | 分页查询系统默认快捷入口。 |
| POST | `/home/admin/workbench/quick-entry/save` | `home:card:manage` | 新增或编辑系统默认快捷入口。 |
| POST | `/home/admin/workbench/quick-entry/status` | `home:card:manage` | 启用或停用系统默认快捷入口。 |

后续如需拆分卡片数据接口，可按卡片能力扩展为 `/home/workbench/todo`、`/home/workbench/metrics` 等专用接口，但统一布局接口必须保持稳定。

## 数据模型方向

一期建议新增工作台配置表、用户布局表和快捷入口表。字段说明以 `docs/03-database/tables.md` 为准，实际建表时必须同步 `sql/建表脚本.sql`。

建议表：

- `home_workbench_card`：工作台卡片配置表。
- `home_workbench_user_card`：工作台用户卡片布局表。
- `home_workbench_quick_entry`：工作台快捷入口表，保存系统默认入口和用户个人入口。

设计原则：

- 表必须包含 `tenant_id`、创建/更新审计字段和逻辑删除字段。
- `home_workbench_card.card_code` 在同租户有效数据内唯一。
- 用户布局按 `tenant_id + user_id + card_code` 唯一。
- 快捷入口按 `tenant_id + owner_type + owner_user_id + entry_code` 唯一；系统默认入口的 `owner_user_id` 固定保存 `system`，用户个人入口保存用户 ID。
- 配置 JSON 只存展示参数，不存可执行脚本或任意组件路径。

## 展示计算规则

当前用户可见卡片按以下顺序计算：

1. 查询当前租户启用的卡片配置。
2. 过滤未注册或配置异常的组件。
3. 过滤用户无权限的卡片。
4. 合并当前用户个性化配置。
5. 按用户栅格位置展示；没有栅格位置时使用系统默认排序生成默认位置。
6. 对用户隐藏的卡片不展示，但在个性化设置中可重新打开。

如果系统启用新卡片，且用户没有个性化记录：

- `defaultVisible=1` 时默认展示。
- `defaultVisible=0` 时默认隐藏，但可在个性化设置中打开。

如果系统启用新卡片，但用户已有个性化记录：

- 新卡片仍按系统默认值加入候选列表。
- 不重置用户已有卡片布局和显隐设置。

## 安全与性能要求

- 工作台接口必须按当前用户和当前租户查询数据。
- 卡片权限只决定卡片入口是否可见，业务数据权限仍由各业务模块控制。
- 卡片数据接口不得返回当前用户无权访问的审批、消息、文档或日志。
- 首页聚合接口应避免一次性返回大量明细，每个卡片默认只返回前 5 到 10 条。
- 首页加载应支持分块加载，布局先渲染，再按卡片加载数据。
- 卡片刷新应有最小间隔，避免多个卡片同时高频请求。
- 卡片接口异常只影响单个卡片，不影响整个工作台页面。

## 一期后端 Provider 接入口径

- `todo`：接入审批中心我的待办和我的已办，返回待办、已办总数和明细。
- `cc`：接入审批中心我的抄送，返回未读抄送、已读抄送总数和明细，均按到达时间倒序排列。
- `quick-entry`：接入工作台快捷入口配置，返回当前用户有权访问的系统默认入口和个人入口。
- `message`：接入消息中心收件箱，返回未读消息、已读消息总数和明细；存在未读催办或未读超时提醒时，额外返回对应动态 Tab 统计和明细。
- `favorite`：接入文档中心收藏数据，返回当前用户收藏文件总数及明细，并展开收藏文件夹下的真实文件，按收藏时间倒序排列。
- `metrics`：聚合我的待办、我的抄送和我的消息数量，只作为轻量首页指标。

## 验收口径

- 用户拥有 `home:workbench:view` 后可以进入工作台。
- 管理员可配置卡片名称、权限码、组件、启用状态、默认排序和默认尺寸。
- 卡片未设置权限码时，拥有工作台访问权的用户默认可见。
- 卡片设置权限码时，未授权用户不可见，直接调用卡片数据接口也会被拒绝。
- 用户可隐藏、显示、排序和调整自己有权访问的卡片。
- 管理员停用卡片后，所有用户不再展示该卡片。
- 我的待办、我的抄送、快捷入口、我的消息、我的收藏和指标概览六类卡片均有 loading、empty、error 状态。
- 各卡片点击明细能跳转到对应模块，并继续使用对应模块原有权限校验。
- 工作台不通过首页子菜单模拟卡片，菜单树保持导航语义清晰。
