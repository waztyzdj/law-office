# 首页/工作台模块

首页模块统一命名为“工作台”，用于承载通用管理系统的个人工作入口、待办聚合、抄送消息、快捷入口和轻量指标能力。

首页模块后端目录：

```text
backend/src/main/java/com/lawoffice/home
```

首页模块前端目录：

```text
frontend/src/views/home
```
