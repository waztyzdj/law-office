# 文档中心

## 功能说明

文档中心用于提供用户个人文档、业务文档、租户/部门共享、共享给我、我的共享、收藏、回收站和 ONLYOFFICE 在线预览编辑能力。通用文件元数据、业务关联和 MinIO 对象存储仍由系统文件基础设施提供。

## 代码入口

- 文档中心 Controller：`backend/src/main/java/com/lawoffice/document/controller/DocumentCenterController.java`
- ONLYOFFICE Controller：`backend/src/main/java/com/lawoffice/document/controller/OnlyOfficeDocumentController.java`
- 文档中心 Service：`backend/src/main/java/com/lawoffice/document/service/impl/DocumentCenterServiceImpl.java`
- 通用文件基础设施：`backend/src/main/java/com/lawoffice/system/service/impl/SysFilesServiceImpl.java`
- 前端页面：`frontend/src/views/document/center`

## 数据表

- `sys_files`：文件元数据
- `sys_file_version`：文件历史版本
- `sys_file_acl`：文件访问授权
- `sys_file_relation`：文件与业务对象的关联

## 接口前缀

- `/document/files`
- `/document/files/onlyoffice`

## 关键规则

- 文件元数据和业务关联分离。
- 文件对象由服务端生成 key。
- 所有上传、查询和绑定操作都应校验租户与文件状态。
- 通用附件单文件大小上限为 50MB，超过限制时返回 413。
- 文档中心上传采用文件类型白名单，仅允许常规文档、图片和视频文件，禁止上传可执行文件、脚本和压缩包等高风险类型。
- 文件中心通用详情和下载接口仅允许上传人访问；受保护业务附件必须通过对应业务模块接口下载，并由业务模块校验成员、收件人、审批人等访问权限。
- 文件下载由后端按 `sys_files.file_name` 设置下载文件名，避免暴露对象存储 key 或产生中文乱码。
- 文档中心使用 `sys_files.parent_id` 表示文件夹层级，`iz_folder=1` 表示文件夹。
- 文档中心共享使用 `sys_file_acl`，目标类型为 `user`、`depart`、`role`、`tenant`，权限为 `read`、`download`、`update`、`manage`。
- 在线编辑历史版本使用 `sys_file_version` 保存不可变 MinIO 对象。上传支持历史预览的文档时生成 `upload` 初始版本；ONLYOFFICE `status=6` 强制保存只覆盖当前文件，不生成历史版本；`status=2` 最终保存按 SHA-256 去重后生成 `final` 版本。
- 历史版本只允许只读预览，不允许编辑历史版本本身；恢复历史版本需要当前文件 `update/manage` 权限，恢复后覆盖当前文件并新增 `restore` 类型版本记录。
- 文档中心第一期支持“我的文档、业务文档、租户共享、部门共享、共享给我、我的共享、我的收藏、回收站”；上传、新建文件夹、重命名、移动、删除、恢复和共享仅允许文件拥有者操作；复制粘贴允许复制当前用户可下载的文件或可访问文件夹，并为文件副本生成新的对象存储文件。
- 回收站中不支持新增、重命名、复制、剪切、粘贴、移动、拖拽、收藏、共享、在线编辑和历史版本恢复；文件夹只允许恢复或彻底删除，文件只允许预览、下载、恢复或彻底删除。文件夹移入回收站后保留原有层级，根目录只展示已删除文件夹树的顶层节点，彻底删除会同步清理授权、个人归类关系、历史版本记录和对象存储文件。
- 租户共享、部门共享和我的文档一样支持上传文件、新建文件夹、重命名、移动、复制、删除、收藏、共享和在线编辑；区别是根目录数据权限分别由当前租户 ID、当前部门 ID 控制，进入子目录后按文件夹层级继承该共享目标。共享给我不支持上传文件，但支持新建个人整理文件夹，并可把共享给我的文件拖入个人整理文件夹归类。
- 共享给我的个人归类复用 `sys_file_relation` 记录当前用户的整理关系，不修改被共享文件原始 `parent_id`，避免影响文件所有者和其他共享成员。
- 我的收藏聚合展示当前用户已收藏且未删除的文件和文件夹；进入收藏文件夹后按该文件夹原有层级浏览其直接子级。
- “业务文档”是与“我的文档”平行的独立分类，用于展示当前用户有业务访问权且仍存在业务关联的文档；消息附件等业务文档按业务模块访问权展示，例如消息发件人和收件人均可查看。业务文档根目录先按业务模块展示虚拟文件夹（`store_type=business_module_view`），进入模块后再按业务数据核心字段展示虚拟文件夹（`store_type=business_record_view`），进入具体业务数据后展示附件。业务附件不允许在文档中心上传、重命名、移动、复制、删除或在线编辑，只有业务数据解除附件关联后才能回到普通文档流程清理。
- 用户头像等系统内部附件不进入业务文档分类；需要排除的内部附件业务类型必须在文档中心服务中集中维护，避免散落在各业务 Provider 中。
- 业务文档在文档中心内按只读浏览处理：文件夹只允许打开查看，文件只允许下载和预览，不允许新增、重命名、删除、拖拽、复制、剪切、粘贴、移动、共享、收藏、在线编辑或历史版本恢复。历史数据中如存在 `store_type=business_view` 的个人整理文件夹，仍可作为只读目录展示；`sys_file_relation` 中 `relation_type=3`、`biz_type=document_business:<userId>` 的历史个人归类关系仅用于兼容展示，不再从文档中心产生新的归类关系。
- 业务文档接入点是 `IBusinessDocumentProvider`。新增业务模块只需要继续使用 `sys_file_relation.biz_type/biz_id` 绑定附件，并实现 Provider 返回模块名称、业务数据目录名称和访问权限判断；文档中心不应新增面向具体业务模块的 `if/else` 定制逻辑。
- 文档中心左侧搜索为全局搜索，按当前用户查询权限检索本人未删除文件、被共享文件以及被共享文件夹下的子级文件，结果展示在右侧区域。搜索结果按只读浏览处理：文件只允许预览和下载，多选时只允许批量下载；不允许新增、重命名、删除、拖拽、复制、剪切、粘贴、移动、共享、收藏、在线编辑或历史版本恢复。
- 租户共享和部门共享只展示当前用户所属租户/部门共享空间中的文件树，不展示别人通过显式共享按钮按租户或部门授权给当前用户的文件；别人授权给当前用户的文件统一进入“共享给我”。租户共享根目录以当前租户 ID 作为数据权限目标，部门共享根目录以当前部门 ID 作为数据权限目标。
- “我的共享”根目录展示本人直接共享出去的文件/文件夹和本人创建的共享整理文件夹；进入已共享文件夹后按原文件夹层级展示直接子级，子文件不需要逐条写共享授权。
- “共享给我”支持打开被共享文件夹并浏览其子级；下载必须具备 `download` 及以上权限且文件未禁用下载。
- 前端支持图标和列表两种浏览模式，浏览模式缓存到本地；两种模式都必须保持单击选中、双击打开或下载、右键菜单、拖拽、多选和剪切虚化等操作系统式交互一致。
- 文档中心快捷键按主流操作系统习惯实现：`Ctrl/Command + X` 剪切、`Ctrl/Command + C` 复制、`Ctrl/Command + V` 粘贴、`Delete` 删除，macOS 同时支持 `Command + Backspace` 删除；`Ctrl/Command + 单击` 支持间隔多选，`Shift + 单击` 支持连续多选。
- 批量移动和批量删除由后端批量接口处理，采用任一失败整体回滚的策略，前端不得循环调用单文件接口造成部分成功状态。
- 文档中心作为通用能力，不做 `files:view`、`files:edit` 功能权限拦截；权限边界由租户、所有者和共享授权数据规则控制。
- 左侧树首次进入时调用 `POST /document/files/tree/batch` 一次加载多个根分类的首层文件夹，并依赖后端返回的 `hasChild` 判断是否展示展开图标；根分类默认不展开。用户展开某一级时先加载当前级子目录，同时调用 `POST /document/files/tree/prefetch` 批量预取这些子目录的下一层文件夹并写入前端缓存，但不自动展开。新增、重命名、删除、移动、粘贴或拖拽目录后，应优先局部刷新受影响节点，避免整棵树刷新导致展开状态丢失。

## 前端菜单与交互规则

文档中心前端的菜单规则必须按“被操作节点所在的左侧根分类”计算，不能只按当前右侧已打开目录的 `scope` 计算。左侧树节点右键时，应先通过节点 key 解析其所属根分类，再决定菜单内容；否则会出现先右键其他分类节点时沿用上一次左键选中分类菜单的问题。

“实际共享项”指当前记录本身存在有效共享授权，前端以 `sharedFlag=true` 且 `ownerFlag=true` 判断；被实际共享文件夹带出的子文件或子文件夹只是继承可见，不属于实际共享项。“实际收藏项”指当前记录本身被用户收藏，前端以 `izStar=1` 判断；被收藏文件夹带出的子文件或子文件夹只是继承浏览入口，不属于实际收藏项。

### 租户共享和部门共享

- 菜单、快捷键、拖拽、批量操作和操作权限与“我的文档”保持一致。
- 根目录新建、上传或复制出的文件不写 `sys_file_acl`，而是写入对应共享空间：租户共享使用 `sys_files.store_type=tenant_shared`；部门共享使用 `sys_files.store_type=depart_shared`，并通过 `sys_file_relation.biz_type=document_depart_shared`、`biz_id=部门ID`、`relation_type=4` 记录部门共享根目录。
- 进入子目录后按父级共享空间继承目标归属；普通文件移动或复制到共享空间后成为对应共享空间文件，不能跨租户共享和部门共享目标混放。

### 共享给我

- 左侧树节点不提供右键操作菜单，不允许从树节点发起复制、剪切、重命名、删除、共享或拖拽。
- 右侧文件夹不提供操作菜单。
- 右侧文件只允许按共享权限执行预览、在线编辑和下载；不允许重命名、复制、剪切、移动、删除、收藏或共享。
- 多选时只允许下载可下载文件，不允许批量预览、在线编辑、复制、剪切、移动或删除。

### 业务文档

- 左侧树节点不提供右键操作菜单，不允许从树节点发起新增、重命名、删除、复制、剪切、粘贴、移动、共享、收藏或拖拽。
- 右侧文件夹不提供操作菜单，只允许双击或点击进入查看。
- 右侧文件只允许预览和下载；不允许在线编辑、历史版本恢复、重命名、复制、剪切、移动、删除、收藏或共享。
- 空白区域右键只保留排序入口，不显示粘贴、上传或新建文件夹。
- 多选时只允许下载可下载文件，不允许批量预览、在线编辑、复制、剪切、移动或删除。

### 回收站

- 不渲染左侧树节点，不提供新增、上传、粘贴或拖拽入口。
- 右侧文件夹只允许恢复和彻底删除；不允许进入重命名、复制、剪切、移动、共享、收藏、下载或预览。
- 右侧文件只允许预览、下载、恢复和彻底删除；不允许在线编辑、历史版本恢复、重命名、复制、剪切、移动、共享或收藏。
- 空白区域右键只保留排序入口，不显示粘贴、上传或新建文件夹。
- 多选时允许下载可下载文件和批量恢复；彻底删除保持单项操作，避免误操作。

### 我的共享

- 只有实际共享项显示共享相关菜单；实际共享文件夹和实际共享文件允许“查看共享”和“取消共享”。
- 实际共享文件夹下的子文件夹、子文件只是继承浏览入口，不允许查看共享或取消共享。
- 文件夹除实际共享项的共享菜单外，不允许重命名、复制、剪切、移动、拖拽、粘贴或删除。
- 文件只允许按权限执行预览、在线编辑和下载；若文件本身是实际共享项，可额外查看共享或取消共享。
- 多选时只允许下载可下载文件，不允许批量预览、在线编辑、复制、剪切、移动、删除或取消共享。

### 我的收藏

- 只有实际收藏项显示取消收藏菜单；实际收藏文件夹和实际收藏文件允许“取消收藏”。
- 实际收藏文件夹下的子文件夹、子文件只是继承浏览入口，不允许取消收藏。
- 文件夹除实际收藏项的取消收藏菜单外，不允许重命名、复制、剪切、移动、拖拽、粘贴或删除。
- 文件只允许按权限执行预览、在线编辑和下载；若文件本身是实际收藏项，可额外取消收藏。
- 多选时只允许下载可下载文件，不允许批量预览、在线编辑、复制、剪切、移动、删除或取消收藏。
