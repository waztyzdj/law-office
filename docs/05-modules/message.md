# 站内消息模块

站内消息独立于系统管理模块，面向同租户用户提供消息发送、收件箱、发件箱、动作跳转和附件能力。

## 页面

- 收件箱：查看收到的消息，打开详情后自动已读，支持收藏和删除。
- 发件箱：查看发送记录，支持详情、撤回和删除。

## 动作

- 内部页面：通过系统路由跳转，可携带 JSON 路由参数。
- 外部链接：仅允许 `http` 和 `https`。
- 待办任务：预留业务类型和业务 ID，便于后续待办模块接入。
- 附件：通过文件中心上传后，以 `fileId` 绑定消息。

## 数据表

- `sys_message`：消息主表。
- `sys_message_receiver`：收件人、已读、收藏和提醒状态。
- `sys_message_action`：消息动作。
- `sys_message_send_record`：发送批次记录。
